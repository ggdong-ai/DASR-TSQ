
# DASR–TSQ

Decision-Aligned Sibling Ranking and Topology Scaffold Quotas
for Multiobjective Molecular Optimization.

## Overview

DASR–TSQ combines:
- Decision-aligned sibling ranking for candidate prioritization
  in local Monte Carlo tree search.
- Generic Bemis–Murcko scaffold occupancy quotas during
  NSGA-II environmental selection.

## Application

Four-objective molecular optimization involving predicted
GSK3β and JNK3 activity, QED, and synthetic accessibility.

## Repository Structure

- `02_code/`: Core algorithms and experiment scripts
- `configs/`: Frozen experimental configurations
- `data/`: Publicly shareable input and output datasets
- `analysis/`: Statistical analyses
- `figures/`: Figure reproduction scripts
- `results/`: Selected frozen results
